# Interface language sources

Reviewed 2026-10-08. The planned interface uses English with five existing
Noongar labels. These are published expressions, not a complete translation.
No new language words, sentences or translations were generated for this review.

## Source evidence

- Noongar Boodjar Language Cultural Aboriginal Corporation (NBLC):
  https://noongarboodjar.com.au/spelling-and-pronunciation/
- Wirlomin Noongar Language and Stories Inc., Djinang:
  https://www.wirlomin.com.au/language-list/djinang-2/
- NBLC use conditions: https://noongarboodjar.com.au/disclaimer/

These pages were checked earlier in this session. NBLC's greeting context
supports the existing Kaya label; its questions section supports the three
question forms. Wirlomin's entry supports the existing Djinang label.
Source spelling and context should be preserved, rather than combining
sources into new sentences or implying a universal meaning.

## Use conditions and review status

NBLC states that permission is required before using website information,
and that attribution is required. No authorization has been recorded.
The inspected Wirlomin entry has a copyright footer; an explicit reuse
licence has not been established. Permission therefore remains unresolved.
The user previously reported checking the language sources; AI also compared
the expressions with the source pages. Neither check establishes permission.

The labels have identifiable sources, but are not yet cleared for the final
public interface. Before use, obtain appropriate permission or omit the labels
and retain the English interface. No endorsement or community review is claimed.
The language labels do not establish the language or Country of a collection item.
